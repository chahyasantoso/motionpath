# MotionPath v4.2

MotionPath is a data-first animation runtime built on GSAP. The v4.2 package layout is authoritative: `@motionpath/core` owns runtime composition and validation, `@motionpath/react` owns React bindings, and `@motionpath/demo` owns visual scenes.

Start with [the API reference](docs/API-REFERENCE.md), [the v4.2 rig graph plan](docs/V4.2-RIG-GRAPH-PLAN.md), and [the architecture map](docs/ARCHITECTURE.md).

Before merging: `npm test`, `npm run typecheck`, `npm run build`, `npm run pack:check`.
