## Failure semantics

- **Compose failure:** no patch exists, so the node and its downstream closure are blocked for the flush; the node stays state-pending and retries with its dependents next flush.
- **Publish failure:** the patch is valid, so dependents publish in the same flush; only the failed node retries and does not propagate `changed` downstream.
- **Retry budget:** applies only to publish failures. Default is `maxAttempts: Infinity`, `backoff: 0`, preserving prior behavior. Bounded callers can stop retries after N failed publish calls, skip complete flushes between attempts, and call `resetRetry(id)` after renderer recovery. Exhaustion retains the valid cache and stops retrying; errors still surface as `AggregateError`.
