## Settled v4.3 semantics

- **Compose failure:** no patch exists; block the node's downstream closure for the flush, keep it state-pending, and retry source plus dependents next flush. Compose failures never consume publish retry budget.
- **Publish failure:** patch is valid; dependents publish in the same flush, only the failed node retries, and the retry does not enter `changed`.
- **Retry exhaustion:** default `maxAttempts: Infinity`, `backoff: 0` preserves old behavior. Opt-in budgets stop retrying after N failed publish calls, skip configured complete flushes between attempts, retain the valid cache by default, and allow explicit `resetRetry(id)` recovery. Failures still surface as `AggregateError`.
